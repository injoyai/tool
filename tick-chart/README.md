# 分时图 (Tick Chart)

基于 Electron 的桌面分时图浮窗应用，支持 WebSocket 实时数据推送。

## 功能特性

- **系统托盘运行**：程序运行在系统托盘，不占用任务栏
- **分时图展示**：支持 240 条分时数据，不足 240 条时右侧留空
- **WebSocket 实时推送**：连接 `ws://127.0.0.1:12380/minute/ws?code={code}` 获取实时数据
- **颜色反转**：切换白/深色背景主题，涨跌红绿颜色保持不变
- **配置持久化**：自动保存代码、透明度、置顶、颜色反转等配置
- **后台刷新**：窗口失去焦点后数据正常刷新，走势图实时更新
- **隐藏控制栏**：鼠标移到窗口顶部时控制栏滑出显示

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.js` | Electron 主进程，创建窗口、系统托盘、IPC 通信、配置读写 |
| `preload.js` | 预加载脚本，安全暴露 API 给渲染进程 |
| `index.html` | 渲染进程页面，包含分时图 Canvas 绘制和控制栏 |
| `package.json` | 项目配置和构建配置 |

## 启动方式

### 1. 安装依赖

```bash
npm install
```

### 2. 启动应用

```bash
npm start
```

### 3. 编译为 exe

```bash
# 设置环境变量（Windows PowerShell）
$env:LOCALAPPDATA="e:\GOPATH\src\github.com\injoyai\tool\tick-chart\.local-appdata"
$env:CSC_IDENTITY_AUTO_DISCOVERY="false"

# 打包成免安装目录
npm run build:dir

# 打包成安装包（NSIS）
npm run build
```

编译输出目录：`dist/win-unpacked/`

## 分时图说明

- **数据格式**：`[{"Time":"09:30","Price":10000,"Number":23}]`
- **Price 单位**：分，显示时除以 1000 转为元
- **数据量**：最多 240 条，不满 240 条时右侧留空
- **图表元素**：价格折线、均价线、成交量柱状图、昨收线、网格线

## 控制栏

鼠标移到窗口顶部时控制栏滑出显示，包含：

- **代码输入框**：输入股票代码，按回车或失去焦点后连接 WebSocket
- **颜色反转**：切换白/深色背景主题
- **透明度滑块**：0.1 ~ 1.0，步长 0.1
- **置顶**：窗口始终置顶

## 系统托盘

- **单击托盘图标**：显示/隐藏窗口
- **右键托盘图标**：弹出菜单（显示 / 退出）
- 窗口失去焦点时不会自动隐藏

## 配置文件

位置：`%APPDATA%\floating-browser\config.json`

```json
{
  "opacity": 1.0,
  "alwaysOnTop": false,
  "code": "600519",
  "colorInverted": false
}
```

## IPC 通信

| 事件 | 说明 |
|------|------|
| `set-opacity` | 设置窗口透明度 |
| `set-always-on-top` | 设置窗口是否置顶 |
| `set-code` | 保存股票代码到配置 |
| `set-color-inverted` | 保存颜色反转状态到配置 |
