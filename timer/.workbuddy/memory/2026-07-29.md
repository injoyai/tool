# 2026-07-29 定时任务项目重构

## 脚本引擎: JS(otto) → Go(yaegi)

- 新建 `script.go`,基于 `github.com/traefik/yaegi v0.16.1` 实现 Go 脚本引擎
- 内置 `funcs` 包提供:Start/Ping/Notice/Dial/DialTCP/Print/Println
- 每次 Exec 独立创建 Interpreter,Use(stdlib + lib.Symbols + 自定义 funcs)
- 脚本必须写完整 Go 程序(`package main` + `func main`)
- 保留 SetFunc 动态注册能力

## lib 符号包裁剪与重构

- 删除 ios/frame/bar 等无法兼容当前依赖版本的符号(旧 frame v0.0.5 无 fbr/v0.0.20 无 fiber)
- 保留:conv、base(coding/crypt/maps/chans/safe/str/types)、logs
- 用 `yaegi extract` 重新生成符号文件,匹配当前 go.mod 版本
- 解决 ugorji/go/codec 模块歧义(添加 standalone codec v1.2.12)
- 脚本可直接使用 injoyai 库(如 `conv.String()`、`logs.Info()` 等)

## 前端编辑器升级

- 从纯 `<textarea>` 升级为 CodeMirror 5 编辑器
- Go 语法高亮、行号、括号匹配、自动闭合括号
- 静态文件(codemirror.min.js/css + go mode + addons)嵌入到二进制
- 通过 `/static/*` 接口提供,保持单文件部署
- 默认 Go 脚本模板(import fmt/time/funcs)

## 关键修改文件
- `api.go`:移除 js/otto 依赖,改用 newScriptEngine(),添加 /static/ 路由
- `script.go`:新建,yaegi 脚本引擎
- `index.html`:CodeMirror 集成
- `lib/lib.go`:裁剪依赖,保留核心包
- `lib/*.go`:重新 extract 生成
- `static/`:CodeMirror 静态资源

## 编译注意事项
- Go 1.25 vet 有兼容问题,测试需 `-vet=off`,构建正常
- 构建入口:`go build -o timer.exe ./cmd/web/`
- 单文件二进制约 47MB
